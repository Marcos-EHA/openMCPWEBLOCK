## AVAILABLE TOOLS FOR SUPERASSISTANT

 - Read
**Description**: Read file contents from the filesystem. Supports line ranges with offset/limit.
**Parameters**:
- `file_path`: Path to the file to read (string) (required)
- `path`: Alias for file_path (string) (optional)
- `offset`: Starting line number (0-based) (number) (optional)
- `limit`: Number of lines to read (number) (optional)

 - Write
**Description**: Write content to a file. Creates parent directories if needed.
**Parameters**:
- `file_path`: Path to the file to write (string) (required)
- `path`: Alias for file_path (string) (optional)
- `content`: Content to write (string) (required)

 - Edit
**Description**: Edit a file by searching for exact text and replacing it.
**Parameters**:
- `file_path`: Path to the file to edit (string) (required)
- `path`: Alias for file_path (string) (optional)
- `old_text`: Exact text to find (string) (required)
- `new_text`: Replacement text (string) (required)

 - MultiEdit
**Description**: Perform multiple text edits on a file in a single pass.
**Parameters**:
- `file_path`: Path to the file to edit (string) (required)
- `edits`:  (array) (required)
  - Array items (objects) with properties:
    - `old_text`: No description (string)
    - `new_text`: No description (string)

 - Bash
**Description**: Execute a shell command in the system terminal and return stdout/stderr.
**Parameters**:
- `command`: The command to execute (string) (required)

 - ListDir
**Description**: List files and directories within a specified path.
**Parameters**:
- `path`: Directory path to list (defaults to current directory) (string) (optional)

 - Glob
**Description**: Find files matching a glob pattern.
**Parameters**:
- `pattern`: Glob pattern to search for (string) (required)

 - Grep
**Description**: Search for text patterns in files using regex.
**Parameters**:
- `pattern`: Regular expression pattern to search for (string) (required)
- `path`: Directory or file path to search in (string) (optional)

 - WebSearch
**Description**: Search the web using DuckDuckGo and return top results.
**Parameters**:
- `query`: Search query (string) (required)

 - WebFetch
**Description**: Fetch web content from a URL.
**Parameters**:
- `url`: URL to fetch (string) (required)

 - TodoRead
**Description**: Read the project todo/task list.
**Parameters**:
- `path`: Path to todo file (defaults to TODO.md) (string) (optional)

 - TodoWrite
**Description**: Update the project todo/task list.
**Parameters**:
- `path`: Path to todo file (string) (optional)
- `content`: New todo content (string) (required)

 - filesystem.list_allowed_directories
**Description**: List the allowed root directories for filesystem operations.
 - filesystem.read_file
**Description**: Read the contents of a file (alias for Read).
**Parameters**:
- `path`: Path to file (string) (optional)
- `file_path`: Path to file (string) (optional)
- `offset`:  (number) (optional)
- `limit`:  (number) (optional)

 - filesystem.write_file
**Description**: Write contents to a file (alias for Write).
**Parameters**:
- `path`: Path to file (string) (optional)
- `file_path`: Path to file (string) (optional)
- `content`: File content (string) (required)

 - filesystem.list_directory
**Description**: List contents of a directory (alias for ListDir).
**Parameters**:
- `path`: Directory path (string) (optional)

 - shell.execute_command
**Description**: Execute a system command (alias for Bash).
**Parameters**:
- `command`: Shell command (string) (required)

 - filesystem.read_text_file
**Description**: Read the complete contents of a file as text (alias for Read).
**Parameters**:
- `path`: Path to file (string) (required)
- `file_path`: Path to file (string) (optional)

 - filesystem.edit_file
**Description**: Make line-based edits to a text file (alias for Edit).
**Parameters**:
- `path`: Path to file (string) (required)
- `file_path`: Path to file (string) (optional)
- `old_text`: Old text to replace (string) (required)
- `new_text`: Replacement text (string) (required)

 - chrome-devtools-mcp.new_page
**Description**: Open a new tab and load a URL.
**Parameters**:

- `background`: Background loading (boolean) (optional)

**Description**: Get a list of pages open in the browser.

**Parameters**:
